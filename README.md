# Yordamchi — AI Telegram Secretary Bot

Yordamchi is an AI-powered secretary chatbot built for small businesses in Uzbekistan — workshops, shops, salons, and online stores — that don't have staff to monitor Telegram and website chats around the clock.

## What it does
- Answers customer questions in Telegram and on the website automatically, 24/7
- Clarifies order details through natural conversation instead of rigid menus
- Delivers a ready-to-process lead to the business owner instead of a raw chat log
- Average first response time: ~3–5 seconds

## Tech stack
- Make.com (automation/orchestration)
- Telegram Bot API
- AI/LLM integration for natural language understanding

## Live demo
🔗 https://www.getyordamchi.uz

## Why it matters
Small businesses lose leads when nobody responds fast enough — especially outside working hours. Yordamchi closes that gap by acting like a real assistant instead of a static FAQ bot.
